НАШИ ПЛАНЫ — исправленная версия

ЗАПУСК
1. Распакуй архив.
2. Открой index.html в браузере.
3. Интернет нужен для Google Fonts и запасных фотографий, если свои ещё не добавлены.

СВОИ ФОТОГРАФИИ
Внутри папки images лежат файлы-подсказки:
- main.jpg — фон главной страницы;
- timer.jpg — фон секции таймера;
- paris.jpg — карточка Парижа;
- sea.jpg — карточка моря;
- mountains.jpg — карточка гор;
- petersburg.jpg — карточка Санкт-Петербурга;
- home.jpg — карточка уютного вечера дома.

Замени эти файлы своими фотографиями, сохранив точно такие же имена и расширения. Можно удалить пустые файлы-заглушки перед копированием своих фотографий. Если у фото другое расширение, например .png, измени имя в style.css.

ЧТО ИСПРАВЛЕНО
- Крестик и кнопка «Передумал(а)» закрывают окно добавления места; клик по затемнённому фону тоже закрывает.
- Повторное нажатие на выбранную карточку снимает выбор.
- Можно добавлять несколько свиданий на разные даты, удалять их из списка и подтверждать список.
- На телефоне в шапке виден пункт «График».
- Список свиданий сохраняется в localStorage этого браузера.
- Таймер считает до ближайшего подтверждённого будущего свидания.

ВАЖНО
- Погода демонстрационная, не реальный прогноз.
- Это фронтенд без сервера: сохранение работает только в конкретном браузере и не синхронизируется между телефонами.
- Пример графика: вторник и пятница заняты. Чтобы изменить, найди в script.js:
  const isBusy = date => busyDays.has(iso(date)) || date.getDay()===2 || date.getDay()===5;
  Дни недели в JavaScript: 0 — воскресенье, 1 — понедельник, ... 6 — суббота.
- Таймер назначает встречу на 12:00 выбранной даты.
